# Web App Calculator

## Description
A responsive web application calculator supporting basic arithmetic operations with a simple and clean user interface.

## Features
*   Supports addition, subtraction, multiplication, and division.
*   Simple and clean user interface.
*   Responsive design for various devices.
*   Displays current input and calculation result.
*   Clear operation for reset.

## Tech Stack
*   **Frontend:** HTML/CSS/JavaScript
*   **Backend:** None
*   **Database:** None

## How to Run
1.  **Clone the repository (if applicable) or save the files locally:**
    Ensure you have the `frontend/index.html`, `frontend/style.css`, and `frontend/script.js` files in their respective `frontend` folder.
2.  **Navigate to the project root directory in your terminal.**
3.  **Install `http-server` globally (if you don't have it):**
    ```bash
    npm install -g http-server
    ```
4.  **Run the application using `http-server`:**
    ```bash
    npx http-server frontend
    ```
    This command will serve the `frontend` directory.
5.  **Open your web browser** and navigate to the address provided by `http-server` (usually `http://127.0.0.1:8080` or `http://localhost:8080`).

Alternatively, you can simply open `frontend/index.html` directly in your web browser, but a local server is recommended for best practice.
